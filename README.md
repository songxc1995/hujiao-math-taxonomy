# 沪教版小学知识图谱（自建项目）

面向上海小学（五·四学制）的知识点结构项目，先搭骨架、后填内容。数学一～五年级全覆盖，英语从一年级上册（牛津上海版新版）起步。

## 现状

- 已有：一～五年级知识点树（数学：一年级～三年级按沪教版新版目录整理 115 个知识点；四、五年级按旧版（试用本）目录整理：四年级 48、五年级 46，共 209 个知识点；英语：一年级上册、三年级上册按牛津上海版新版目录整理各 22 个知识点，三年级下册按平台目录映射 16 个知识点，另 Project 1/2 4 个知识点；二年级上册、下册按平台同步课堂目录整理各 24 个知识点（无教材页码）；合计 321 条），每条含原创描述与掌握标准
- 已有：原创题目 2889 道（每知识点 9 道：基础 1、中等 4、较难 4），先修关系 312 条
- 说明：三年级下册条目在平台上未标“五·四学制”（归在“小学”下），与上海五四制下册的等价性未在页面上证实，本项目按该册内容做映射；二年级上册、下册条目均以平台同步课堂目录为依据，平台教材栏目无二年级条目、无教材页码、无出版社与 2022 课标字样，与教材页码映射不等价
- 校验：`python3 scripts/validate.py`，通过打印 `VALIDATION PASSED`
- 摸底：`python3 scripts/quiz.py list` 列出知识点，`python3 scripts/quiz.py ask <知识点id>` 出题练习，进度记入 `quiz-progress.json`（不入库）；判分归一化：全半角统一、去空白、英文字母不分大小写

## 目录结构

```
data/
  topics.json        知识点：id、名称、年级、学期、单元、小节、页码、类型、描述、掌握标准
  questions.json     题目（2889 道原创：每知识点 9 道）
  dependencies.json  先修关系（312 条）
  schema.md          字段说明
scripts/
  validate.py        标准库校验脚本（含选项、验算表达式检查）
  quiz.py            摸底小工具：列知识点、出题、判分、记进度
```

## 内容来源与版权边界（重要）

- 知识点名称、单元结构、页码来自沪教版一年级新版教材的**公开目录事实**，事实本身不受版权保护。
- 本项目**没有复制任何其他题库的题目、讲解、描述文本**。结构思路（知识点表 + 题目表 + 先修边 + 校验脚本）是通用的知识图谱做法。
- 后续填写的题目必须全部原创：知识点可以相同，但题面、干扰项、讲解要自己写。
- 本项目协议为 MIT；作者后续原创内容归作者所有。
