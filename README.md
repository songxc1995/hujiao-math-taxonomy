# 沪教版小学数学知识图谱（自建项目）

面向上海小学（五·四学制）数学的知识点结构项目，先搭骨架、后填内容。

## 现状

- 已有：一年级上下册知识点树（按沪教版新版目录整理，共 52 个知识点）
- 未有：题目（`data/questions.json` 为空）、先修关系（`data/dependencies.json` 为空）
- 校验：`python3 scripts/validate.py`，通过打印 `VALIDATION PASSED`

## 目录结构

```
data/
  topics.json        知识点：id、名称、年级、学期、单元、小节、页码、类型
  questions.json     题目（空，待原创填写）
  dependencies.json  先修关系（空，待补充）
  schema.md          字段说明
scripts/
  validate.py        标准库校验脚本
```

## 内容来源与版权边界（重要）

- 知识点名称、单元结构、页码来自沪教版一年级新版教材的**公开目录事实**，事实本身不受版权保护。
- 本项目**没有复制任何其他题库的题目、讲解、描述文本**。结构思路（知识点表 + 题目表 + 先修边 + 校验脚本）是通用的知识图谱做法。
- 后续填写的题目必须全部原创：知识点可以相同，但题面、干扰项、讲解要自己写。
- 本项目协议为 MIT；作者后续原创内容归作者所有。

## 路线图

1. 骨架（本阶段）：一年级知识点树 + 校验脚本
2. 原创题目：按知识点逐个写，不搬运任何现有题库
3. 扩展：二、三年级知识点树；摸底小工具（按知识点出题、记录薄弱点）
