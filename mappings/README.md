# 映射数据说明

本目录是作者本人的沪教版对照工作：只记录"知识点在沪教版的落点"（年级、学期、单元、小节、置信度），**不含任何题库题目内容**。

| 文件 | 内容 |
|------|------|
| `hujiao_math.json` | 160 条，提交给上游的 PR 版（按作者规范的 mappings 格式） |
| `mappings-hujiao-math.json` | 242 条完整版（含无对应与待补判），人读对照表见 `docs/mapping-table.md` |
| `mappings-hujiao-english.json` | 一年级英语 22 条（本地版；上游校验器目前只收数学，故未进 PR） |

详细对照表与过程文档在 `docs/`，教材目录原文在 `catalogs/`。上游题库题目、复核报告、重复题清单等与题目内容相关的材料不在本仓库（见根目录 README 的版权边界）。
