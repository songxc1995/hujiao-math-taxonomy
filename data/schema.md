# 数据字段说明

## topics.json：知识点（数组）

| 字段 | 说明 |
|------|------|
| id | 知识点编号，数学格式 `hjm_g{年级}{学期}{u单元号}_l{小节号}`，如 `hjm_g1a_u3_l1`（a=上册，b=下册）；英语格式 `hje_g{年级}{学期}{u单元号}_l{小节号}`，如 `hje_g1a_u1_l1` |
| subject | 学科：`math`（数学，缺字段时默认）/ `english`（英语） |
| name | 小节名称（来自教材目录） |
| grade | 年级（数字） |
| term | 学期：`上` / `下` |
| unit | 单元名称 |
| unit_no | 单元序号（数字） |
| page | 小节起始页码（教材印刷页） |
| kind | 类型：`概念` / `技能` / `活动` / `应用`（暂定，后续可调） |
| description | 知识点描述（待原创填写，现为空） |
| mastery | 掌握标准（字符串数组，待原创填写，现为空） |

说明：目录中的「小练习」「复习」是练习环节，不是知识点，不建条目。

## questions.json：题目（数组，现为空）

| 字段 | 说明 |
|------|------|
| id | 题目编号，格式 `{知识点id}_q{序号}` |
| topicId | 所属知识点 id，必须存在于 topics.json |
| difficulty | 难度：`basic` / `medium` / `hard` |
| type | 题型：`numeric`（填数）/ `choice`（选择）/ `text`（文字作答） |
| prompt | 题面（必须原创） |
| answer | 答案 |
| explanation | 讲解（必须原创） |
| options | choice 题必填：字符串数组，至少 3 项；answer 必须是其中之一 |
| verify | 可选：答案机算验证表达式，如 `3+1` |

### verify 安全求值规则

- 表达式只允许数字常量与 `+` `-` `*` `/` `(` `)`（含一元正负号），校验时用 `ast` 解析后递归求值。
- 出现其他一切成分（变量名、函数调用、属性访问、幂运算等）一律拒绝，校验报错。
- 求值结果与 answer 按数值比较：整数与小数写法等价（如 `4` 与 `4.0` 视为相等），误差容限 1e-9。
- answer 本身无法解析为数字时，校验报错。

## dependencies.json：先修关系（数组，现为空）

每条为 `{"from": "先修知识点id", "to": "后续知识点id"}`，两端 id 必须存在于 topics.json，且不能自指。
