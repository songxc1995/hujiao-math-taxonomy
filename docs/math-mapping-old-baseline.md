# 沪教版小学数学适配对照表底稿（2026-10-23）

## 口径与方法

- 对照基准：沪教版旧版（试用本）目录，见 `hujiao-math-catalog.md`（含来源与版次说明）。新版（2022 课标）一至三年级目录未收集到，一至三年级的映射在落地前需按新版复核。
- 项目侧：`topics.json` 中 `cnm_p*` 知识点共 242 条，其中项目六年级 43 条系按人教六三制编排；上海为五四制，六年级属初中段，该批多在沪教版小学无对应（个别在小学低年级已有，如负数、圆的初步认识）。
- 置信度：**明确**＝沪教版有名称相同或内容对应的课时；**大致**＝内容被覆盖但无同名课时、或命名/口径不同、或仅部分覆盖；**无**＝沪教版小学段没有该知识点（备注中注明其在沪教版的实际学段）。

## 统计

- 映射覆盖：170/242 条有对应（明确 123、大致 47），沪教版小学无此知识点 72 条。
- 有对应者中，与项目同年级 122 条、跨年级 48 条（沪教版编排顺序与人教版差异较大，跨年级属正常）。
