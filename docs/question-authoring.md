# 原创题目编写规范

本项目题目必须全部原创。本文件是写题时的检查清单。

## 基本要求

- 每道题只服务一个知识点，题面、干扰项、讲解全部自己写，不得复制任何现有题库的文本。
- 字段按 `data/schema.md`：id 格式为 `{知识点id}_q{序号}`；difficulty 取 `basic` / `medium` / `hard`；type 取 `numeric` / `choice` / `text`。
- 写完必须跑 `python3 scripts/validate.py`，通过才能提交。

## 难度划分

- basic：概念识别与直接计算。
- medium：两步推理。
- hard：综合应用与易错点。

## 出题要点

- 选择题至少 2 个干扰项，须是真实易错答案，不是随便编的数字。
- 讲解要讲清为什么，不只给答案；涉及计算的写出步骤。
- 数值题尽量填 `verify` 字段（如 `3+1`），让答案可机算验证。

## 红线

- 不搬运任何现有题库的题面、答案、讲解；知识点相同，文字必须不同。
- 不确定的题先空着，不硬编。
